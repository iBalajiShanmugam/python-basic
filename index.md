## Your learning path

```text
Setup → Fundamentals → Values → Decisions → Collections
      → Functions → Files → Safe programs → Modules → Projects
```

Follow the lessons in order. Mark each completed lesson, and the website will remember progress in this browser.

## A lesson has everything on one page

- beginner analogy and visual mental model;
- carefully explained examples and expected output;
- an important behavior learners often miss;
- three Bug Hunter exercises;
- ten practice problems;
- collapsed hints and solution ideas;
- homework, checkpoint, and next lesson.
