# Project 03 - Student Marks Analyzer

Accept a student's name and marks for several subjects. Display total, average, highest mark, lowest mark, pass/fail status, and grade.

## Required concepts

Lists, loops, functions, conditions, and validation.

## Stretch goal

Analyze multiple students using dictionaries.
