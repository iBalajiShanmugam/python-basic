# Project 05 - Expense Tracker

Create expenses with a date, category, description, and amount. Support adding expenses, listing them, calculating totals, and filtering by category.

## Required concepts

Functions, lists or dictionaries, files, JSON or CSV, and exception handling.

## Stretch goal

Add monthly summaries and a command-line interface.
