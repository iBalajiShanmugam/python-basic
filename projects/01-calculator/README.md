# Project 01 - Calculator

Build a calculator that accepts two numbers and an operation. Support addition, subtraction, multiplication, and division. Display a useful message for an unknown operation and division by zero.

## Required concepts

Input, conversion, operators, conditions, and functions.

## Stretch goal

Keep the calculator running until the user chooses to exit.
