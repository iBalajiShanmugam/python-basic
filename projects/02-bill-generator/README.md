# Project 02 - Bill Generator

Accept customer details and multiple item prices, calculate subtotal, discount, tax, and final total, then print a readable receipt.

## Required concepts

Input, lists, loops, functions, formatting, and conditions.

## Stretch goal

Save the receipt to a text file.
