# Glossary

| Term | Meaning |
|---|---|
| Argument | A value supplied to a function call |
| Boolean | A value that is `True` or `False` |
| Expression | Code that produces a value |
| Function | Reusable block of logic |
| Immutable | Not changeable in place |
| Iterable | A value that can be visited item by item |
| Keyword | A reserved word with Python meaning |
| Module | A Python file that can be imported |
| Mutable | Changeable after creation |
| Parameter | A named input in a function definition |
| Exception | A runtime event that interrupts normal execution |
| Scope | The region where a name can be accessed |
| Statement | An instruction Python can execute |
| Virtual environment | An isolated Python project environment |
