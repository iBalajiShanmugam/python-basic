# Hints

1. Use three `print()` calls.
2. Store each value before printing.
3. Indented blocks need four spaces.
4. A name cannot begin with a digit or be a keyword.
5. Keep the header values separate.
6. Use names such as `title` and `author`.
7. Trace assignments from top to bottom.
8. Rename using lowercase words joined by underscores.
9. Use multiplication inside an f-string.
10. Rename the keyword variable.
