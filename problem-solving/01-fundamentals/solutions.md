# Solution notes

1. Use `print("Name: ...")` on three lines.
2. `print(f"{product}: {price}")`.
3. Put the body under the `if` line with four spaces.
4. Reject names beginning with digits, containing `$`, or matching a keyword.
5. Use one `print()` for each header line.
6. `title = ...`, `author = ...`, then format both.
7. The final value is the last value assigned to each name.
8. Example: `total_price`, `student_name`.
9. `print(f"{number} x 1 = {number}")`.
10. Replace the keyword with a descriptive identifier such as `class_name`.
