# Hints

1. Codes and phone numbers are usually strings.
2. Use `type(value)`.
3. Area is length multiplied by width.
4. Quote the value to preserve zeroes.
5. Compare the order total with the free-delivery limit.
6. Trace literals and expressions one by one.
7. Meaning matters, not only appearance.
8. Keep each field in a clearly named variable.
9. Use `value is None`.
10. Write a type next to every field before coding.
