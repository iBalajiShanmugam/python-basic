# Variables and Data Types Problems

[Back to lesson](../../02-variables-and-data-types/lesson.md) · [Hints](hints.md) · [Solutions](solutions.md)

For every problem, explain why you chose each data type. Write the input, output, one example, and one edge case before coding.

1. Choose types for name, age, salary, employee code, active status, and missing value.
2. Print the type of six values.
3. Calculate the area of a rectangle using numeric variables.
4. Represent a phone number without losing a leading zero.
5. Store a boolean result for whether a customer is eligible for free delivery.
6. Predict the type of each value in ten assignments.
7. Explain why two variables with equal values can have different meanings.
8. Create a product record using separate variables and display it.
9. Write a program that reports whether a value is `None`.
10. Design the data types for a simple student record and justify each choice.
