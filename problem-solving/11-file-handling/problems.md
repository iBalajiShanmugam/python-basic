# File Handling Problems

[Back to lesson](../../11-file-handling/lesson.md) · [Hints](hints.md) · [Solutions](solutions.md)

For every problem, decide what the file should contain before coding. Include the file mode, record format, and missing-file behavior in your plan.

1. Write three lines to a text file.
2. Read and print a file line by line.
3. Count lines and words in a file.
4. Append a new expense to a file.
5. Copy the contents of one file into another.
6. Read a CSV-style file and calculate a total column.
7. Save a list of students as JSON.
8. Load JSON and display students above a mark threshold.
9. Build a file-based notes application.
10. Build an expense tracker that persists data and calculates a total.
