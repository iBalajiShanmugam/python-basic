# Operators Problems

1. Calculate the quotient and remainder of two numbers.
2. Calculate simple interest.
3. Check whether a number is between two limits.
4. Check whether a user can access a system using two boolean conditions.
5. Calculate the final price after tax and discount.
6. Predict the output of ten expressions involving precedence.
7. Explain the difference between `/`, `//`, and `%` with examples.
8. Test whether a character occurs in a string.
9. Compare two values correctly without using `is` for value comparison.
10. Build a delivery eligibility expression from weight, distance, and membership.
