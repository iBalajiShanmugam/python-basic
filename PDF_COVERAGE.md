## Foundation additions made from the PDF

- Bitwise operators
- `for-else` and `while-else`
- Command-line arguments
- Additional built-in types preview: `bytes`, `bytearray`, and `frozenset`
- Multiple return values and built-in versus user-defined functions

These are included carefully with simple examples. A student can skip the optional parts and still complete the main Basic path.

## Topics reserved for Intermediate Python

These topics are present in the PDF but need earlier foundations or more careful treatment:

- Lambda functions
- `map()`, `filter()`, and `reduce()`
- Nested functions
- Decorators and decorator chaining
- Generators and iterators
- Pickling and unpickling
- Regular expressions
- Logging
- Assertions
- Deeper object-oriented programming

## Topics reserved for Advanced Python

- Classes and object design in depth
- Inheritance, polymorphism, abstraction, and special methods
- Multithreading and synchronization
- Thread communication and queues
- Database programming
- Performance, memory, and garbage collection
- Production packaging and deployment

The Basic course is not missing these topics; they are intentionally placed in the next levels so a first-time learner is not overloaded.
