# 08 - Lists and Tuples

## What you will learn

Ordered collections, indexing, mutation, list methods, tuples, and unpacking.

```python
marks = [72, 88, 91]
marks.append(79)
marks[0] = 75
print(marks[1:3])

point = (10, 20)
x, y = point
```

Use a list when the collection changes. Use a tuple for a fixed group of related values.
