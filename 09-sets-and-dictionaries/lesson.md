# 09 - Sets and Dictionaries

## What you will learn

Unique collections and key-value data.

```python
tags = {"python", "beginner", "python"}
print(tags)  # duplicate is removed

student = {"name": "Meera", "marks": 86}
student["passed"] = True
print(student["name"])
```

Use a set for membership and uniqueness. Use a dictionary when a value should be found by a meaningful key.
